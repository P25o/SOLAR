# ตั้งค่าไลบรารี TFT_eSPI สำหรับบอร์ด CYD

**ถ้าไม่ทำขั้นตอนนี้ จออาจขาวโพลน ดำสนิท หรือขึ้นภาพรวน** — ไลบรารี TFT_eSPI ไม่รู้ว่าจอต่ออยู่ขาไหน ต้องบอกมันเอง

บอร์ดของคุณคือ **ESP32-2432S028 (CYD)** จอ 2.8 นิ้ว 320×240

---

## ✅ สถานะปัจจุบัน: ทำไปแล้ว

ตรวจสอบเมื่อวันที่จัดทำเอกสารนี้ พบว่าเครื่องได้ติดตั้ง TFT_eSPI และตั้งค่า `User_Setup.h`
ให้ตรงกับบอร์ด ESP32-2432S028 เรียบร้อยแล้ว **ไม่ต้องทำขั้นที่ 1-3 ซ้ำ**

ขั้นตอนด้านล่างเก็บไว้เผื่อต้องติดตั้งใหม่ หรือย้ายไปทำบนเครื่องอื่น

---

## ขั้นที่ 1 — ติดตั้งไลบรารี

Arduino IDE → **Sketch → Include Library → Manage Libraries** → ค้นหา **`TFT_eSPI`** (ของ Bodmer) → **Install**

---

## ขั้นที่ 3 — แทนที่ทั้งไฟล์

**ลบเนื้อหาเดิมทั้งหมด** แล้ววางอันนี้ลงไป

```cpp
// ===== CYD / ESP32-2432S028 — จอ 2.8" 320x240 =====

#define ILI9341_2_DRIVER

#define TFT_WIDTH  240
#define TFT_HEIGHT 320

#define TFT_MISO 12
#define TFT_MOSI 13
#define TFT_SCLK 14
#define TFT_CS   15
#define TFT_DC    2
#define TFT_RST  -1

#define TFT_BL   21
#define TFT_BACKLIGHT_ON HIGH

// จอสัมผัส (โปรเจกต์นี้ไม่ได้ใช้ แต่ประกาศไว้กันไลบรารีงง)
#define TOUCH_CS 33

#define LOAD_GLCD
#define LOAD_FONT2
#define LOAD_FONT4
#define LOAD_FONT6
#define LOAD_FONT7
#define LOAD_FONT8
#define LOAD_GFXFF
#define SMOOTH_FONT

#define SPI_FREQUENCY       55000000
#define SPI_READ_FREQUENCY  20000000
#define SPI_TOUCH_FREQUENCY  2500000
```

**บันทึกไฟล์ → ปิด Arduino IDE แล้วเปิดใหม่** (สำคัญ ไม่งั้นมันยังจำค่าเก่า)

## 🔧 ถ้าจอยังไม่ถูกต้อง

CYD มีหลายรุ่นย่อย ใช้ชิปจอไม่เหมือนกัน ลองไล่ตามตารางนี้ (แก้ทีละอย่าง แล้วอัปโหลดใหม่ทุกครั้ง)

| อาการ | แก้ยังไง |
|---|---|
| **สีเพี้ยน / สีกลับด้าน** (ขาวเป็นดำ) | เปลี่ยน `ILI9341_2_DRIVER` เป็น `ILI9341_DRIVER` |
| **ภาพรวนเป็นเส้น / มั่ว** | บอร์ดคุณอาจใช้ชิป ST7789 — เปลี่ยนเป็น `ST7789_DRIVER` แล้วเพิ่มบรรทัด `#define TFT_RGB_ORDER TFT_BGR` |
| **สีแดงกับน้ำเงินสลับกัน** | เพิ่ม `#define TFT_RGB_ORDER TFT_BGR` |
| **จอดำสนิท แต่โค้ดรันอยู่** (Serial Monitor มีข้อความ) | แสงหน้าจอไม่ติด — เช็กว่า `TFT_BL` เป็น 21 |
| **ภาพกลับหัว / อยู่ผิดด้าน** | แก้ `tft.setRotation(1)` ใน `display_unit.ino` เป็น 3 |
| **จอขาวโพลนตลอด** | ยังไม่ได้บันทึก `User_Setup.h` หรือลืมปิด-เปิด Arduino IDE ใหม่ |

> บอร์ดของคุณมีทั้งช่อง micro-USB และ USB-C ซึ่งเป็นรุ่นที่ผลิตใหม่ **บางล็อตใช้ชิป ST7789 แทน ILI9341** ถ้าลองค่าตั้งต้นแล้วภาพรวน ให้ข้ามไปลอง `ST7789_DRIVER` ได้เลย

## ✅ วิธีดูว่าสำเร็จ

บนจอต้องเห็น

```
┌──────────────────────────────────┐
│  Solar Charging Station          │  ← แถบฟ้า
├────────────────┬─────────────────┤
│ BATTERY        │ GENERATOR       │
│ 0%             │ 0.0             │
│ 0.00 V         │ VOLT            │
├────────────────┴─────────────────┤
│ CHARGING STATUS                  │
│ READY                            │
│ Scan QR to start charging        │
└──────────────────────────────────┘
  WiFi OK  192.168.x.x
```

ตัวเลขเป็น 0 ถือว่าปกติ เพราะบอร์ดคุมสถานียังไม่ได้ส่งข้อมูลขึ้นมา

**ถ้าขึ้น `CONTROLLER OFFLINE` สีแดง** = จอทำงานถูกต้องแล้ว แต่ยังไม่มีข้อมูลใหม่จากบอร์ดที่ 1 — ให้ไปอัปโหลด `station_controller.ino` ต่อ
